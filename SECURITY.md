# Security Policy

## Supported Versions

This framework is an active research project associated with the IEEE GLOBECOM 2026 paper. Security updates are applied directly to the primary development branch.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| < main  | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability, privilege escalation path, or leak within this framework, please do not open a public GitHub issue or pull request. Instead, report it privately to the paper's authors via email:

* **Mubassir Serneabat Sudipto** — msudipto@iastate.edu
* **Shakil Ahmed** — ahmeshak@gvsu.edu
* **Ashfaq Khokhar** — akhokhar@k-state.edu

Please provide a brief summary of the issue, a proof of concept, and steps to reproduce the behavior so we can address it responsibly.
